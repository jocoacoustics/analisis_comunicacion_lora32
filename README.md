# Ensayo experimental de comunicación LoRa32 con Meshtastic
Se ensayó una red inalámbrica Meshtastic con dos Heltec LoRa32 V4, sin depender de cobertura celular para transportar datos entre radios. En el regreso a pie se recibieron posiciones GPS, controles enviados mediante enlaces Google Maps y mediciones de señal (SNR/RSSI).
